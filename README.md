CareerSync AI 

Developed a web application that leverages AI to compare resumes against job descriptions, highlighting matching/missing skills and generating a similarity score. Implemented real-time skill extraction and matching logic with a FastAPI backend, integrated seamlessly with a React + Material-UI frontend. Built an interactive, responsive UI providing instant feedback and actionable resume improvement suggestions.

LIVE LINK: careersyncai.netlify.app

Tech Stack 
- Frontend: React 
- Backend: FastAPI 

Features 
- Resume parsing 
- Job–resume similarity scoring 
- Missing skill detection 
- Improvement suggestions 
- Clean API architecture
